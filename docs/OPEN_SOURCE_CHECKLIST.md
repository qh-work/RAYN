# 开源发布检查清单

每次创建公开仓库或发布新版本前，逐项确认：

## 仓库内容

- 不提交 `.build`、DerivedData、`xcuserdata`、崩溃记录、设备日志或 ChatGPT 项目镜像。
- 不提交 Apple Developer Team、设备 UDID、个人路径、邮箱、位置历史或账号信息。
- 不提交 `.p8`、`.p12`、证书、描述文件、JWT、API key、`.env` 或本机 `xcconfig`。
- 使用全新克隆执行一次 Debug 和 Release 构建，确认公开仓库不依赖本机隐含文件。

## 数据与架构

- View 只能读取统一模型，不直接引用供应商 JSON、URL 或 SDK 类型。
- 天气、空气质量、雷达、海况和地址搜索都从 `ProviderConfiguration` 组合；单独替换其中一项不应改动其他服务或页面。
- 正式启动路径只请求实时数据，不使用截图、演示 JSON 或静态城市兜底。
- 外部服务的许可证、归因、区域覆盖、缓存和调用频率要求与当前版本一致。

## 发布资料

- 由项目所有者明确选择并添加开源许可证；未选择许可证前不要把代码描述为可自由使用。
- 确认项目名称、图标、截图、字体和第三方素材拥有公开发布权。
- README 写明最低 tvOS/Xcode 版本、构建方式、定位权限、数据服务边界和真机测试范围。
- 发布前运行全部单元测试、UI 测试，并在 A12 Apple TV 上验证页面切换、焦点和雷达地图。
