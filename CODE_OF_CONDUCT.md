# Community Code of Conduct

RAYN Weather welcomes contributors of every background and experience level.

## Expected behavior

- Be respectful, patient, and specific when discussing code or design.
- Critique ideas and implementations, not people.
- Respect privacy, attribution, licensing, and responsible-disclosure boundaries.
- Avoid harassment, discrimination, threats, sexualized content, spam, and deliberate disruption.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, and contributions that violate these expectations. Repeated or severe violations may result in a temporary or permanent ban from project spaces.

For a sensitive conduct concern, do not publish private details. Request a private contact path in a minimal issue, or use GitHub's platform reporting tools when the concern involves abuse on GitHub.
